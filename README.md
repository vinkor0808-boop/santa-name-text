# Santa OreSim

Client-side Fabric mod for **Minecraft 1.21.11** that calculates where diamonds and ancient debris generate from the world seed and highlights those positions with boxes.

## Features
- Seed-based ore positions for **diamonds** (cyan) and **ancient debris** (orange)
- Settings menu: key **O**, command `/oresim menu`, or the gear button in [Mod Menu](https://modrinth.com/mod/modmenu)
- Seed input (number or text seed), radius 16–256 blocks, separate toggles per ore
- Commands: `/oresim`, `/oresim on|off`, `/oresim seed <seed>`, `/oresim radius <16-256>`, `/oresim diamonds`, `/oresim debris`, `/oresim reload`

## Requirements
- Fabric Loader ≥ 0.17.3
- Fabric API
- Mod Menu (optional)

## Notes
Positions are only correct if the seed matches the world and the terrain was generated by vanilla world generation. Many servers forbid ore-finding mods – check the server rules before using it in multiplayer.
