# Santa OreSim (Fabric 1.21.11)

Seed-basiertes Block-ESP für Diamanten und Ancient Debris. Add-on zum Santa Client – einfach mit in den mods-Ordner.

Befehle: `/oresim` (Info), `/oresim on|off`, `/oresim seed <seed>`, `/oresim radius <16-256>`,
`/oresim diamonds`, `/oresim debris`, `/oresim filter`, `/oresim reload`. Taste zum An/Aus unter Steuerung → Santa OreSim.

Cyan = Diamant, Orange = Ancient Debris. Gefüllte Box = Erz ist am Client tatsächlich zu sehen.
